## ISOLINE — Thread → Signal → Terrain → System → Network (`film/`)

A 75-second, 1920×1080, 60 fps procedural motion-design film with an original 120 BPM soundtrack, rendered from a single self-contained HTML file (WebGL2 + Web Audio). Five movements take one orange thread through weave, signal, terrain, a 3D exploded interface and a data city, then back to the thread in a seamless loop. See [`film/README.md`](film/README.md) for how it works, how to download and post the video, and how to reproduce the render. The storyboard is in [`film/storyboard.md`](film/storyboard.md).

- `film/final.mp4`: the finished film, ready to download and upload to YouTube, X, Drive and others
- `film/soundtrack.wav`: the original soundtrack
- `film/index.html`: the film itself; open it and click to play
- `film/contact-sheet.png`: frames from the final film on every bar
- `film/v1-15s/`: the original 15-second version
