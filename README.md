## ISOLINE — Thread → Signal → Terrain → System (`film/`)

A 15-second, 1920×1080, 60 fps procedural motion-design film with an original 120 BPM soundtrack, rendered from a single self-contained HTML file (WebGL2 + Web Audio). See [`film/README.md`](film/README.md) for how it works and how to reproduce the render. The storyboard is in [`film/storyboard.md`](film/storyboard.md).

- `film/final.mp4`: the finished film
- `film/soundtrack.wav`: the original soundtrack
- `film/index.html`: the film itself; open it and click to play
- `film/contact-sheet.png`: frames from the final film on every beat
