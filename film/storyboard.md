# ISOLINE — Thread → Signal → Terrain → System → Network

**75.000 s · 1920×1080 · 60 fps · 120 BPM · 4/4 · 150 beats = 37 bars + ½ bar · seamless loop**

The extended cut. The 15-second original lives in `v1-15s/`.

---

## A. Concept declaration

**Every image in this film is an isoline — a line of equal value. Change the field beneath one orange thread and it becomes weave, signal, terrain, system and network, then pulls itself taut again.**

## B. Visual direction (unchanged identity, deeper space)

| | |
|---|---|
| **Typeface** | Inter only: Display Black for hero words and numerals, SemiBold for tracked captions and labels. In the 3D system, numerals and section letters are **extruded solids**. They are built as isobands of the glyphs' own distance fields, so they are made the same way as the terrain. |
| **Palette** | Ink `#0A0A0B`, Paper `#F1EEE6`, Signal Orange `#FF4A1C` (the thread and everything that names it), Cobalt `#2B36FF` (shadowed walls, probe). |
| **Spatial language** | Architectural drawing taken into space: plan, then oblique, then **exploded axonometric**. The interface is a set of physical slabs with real thickness, separate depth layers, lit edges and soft drop shadows on the paper ground. |
| **Motion vocabulary** | Binary subdivision (the thread splits 1→256; the map later splits into 1→32 tiles; both merge back in reverse), ratchet rotation, phase shift, λ→∞ stretch, extrusion cascades, hinge folds, drum-odometer rolls, magnetic spring docking, traveling activation waves. |

## E. Continuity map (new links)

| Hand-off | What carries the geometry across |
|---|---|
| **Signal → Relief** | The letters' phase shift becomes vertex height. The same lines climb the letter walls, and nothing is added. |
| **Terrain → Tectonic shift** | One field interpolating between two landforms, with the isoband mesh rebuilt from it every frame. |
| **Sheet → Slabs** | The flat interface already is the slab tops. The explode only adds depth: thickness, layer height and shadows. Wires are the existing projection lines given a third dimension. |
| **Slabs → Tiles** | The panels dock into the map slab. The map is then cut by binary subdivision, the same operation that multiplied the thread. |
| **Tiles → Towers** | Each tile's height is its own mean elevation. The city is the terrain re-sampled as data, and the tops still form the map. |
| **Towers → Map → Monument** | Tiles merge back seamlessly into one block (the same mosaic, reassembled). The block's field morphs into the letter field. |
| **Monument → Thread → Loop** | As in the original: plan title, then stripes, then reverse binary merge. From 74.75 s the motion is evaluated by the opening's own functions, and 75.000 equals 0.000. |
